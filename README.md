# PythonApplication1# AttendanceSystem

AttendanceSystem — консольное приложение для учёта посещаемости занятий студентами. Проект предназначен для автоматизации процессов учёта присутствия студентов на занятиях, формирования отчётов и анализа пропусков.

Приложение позволяет регистрировать пользователей, выполнять авторизацию и работать с данными о группах, студентах, дисциплинах и посещаемости.

## Возможности

В проекте реализованы следующие основные возможности:

* регистрация пользователей;
* авторизация пользователей;
* управление студентами;
* управление группами;
* управление дисциплинами и расписанием;
* отметка посещаемости на занятии;
* просмотр своей посещаемости студентом;
* формирование отчётов по группе;
* анализ систематических пропусков;
* хранение данных в базе данных.

## Архитектура

Приложение построено с использованием многослойной архитектуры.

```text
Пользователь
     │
     ▼
Консольный интерфейс
(main.py, menu.py, auth.py)
     │
     ▼
Сервисный слой
(services)
     │
     ▼
Слой доступа к данным
(repositories)
     │
     ▼
База данных
(database)
```

Такое разделение позволяет отделить пользовательский интерфейс от бизнес-логики и операций с данными.
## Основные компоненты
PythonApplication1.py
Точка входа в приложение. Выполняет инициализацию необходимых компонентов и запускает программу.

Бизнес-логика
Содержит правила работы системы: проверку прав доступа, расчёт процента посещаемости, контроль порога пропусков.

Слой доступа к данным
Содержит компоненты, отвечающие за получение, добавление, изменение и удаление данных о посещаемости.
## Требования
Для запуска проекта необходимо установить:

* Python 3.10 или выше;
* Git.
## Установка

## 1. Клонирование репозитория

```bash
git clone https://github.com/elitwice18-svg/PythonApplication1.git
cd PythonApplication1
```
## 2. Создание виртуального окружения

```bash
python -m venv .venv
```
## 3. Активация виртуального окружения

Windows:

```cmd
.venv\Scripts\activate.bat
```
Linux и macOS:

```bash
source .venv/bin/activate
```
## 4. Установка зависимостей

```bash
pip install -r requirements.txt
```
## Запуск приложения
Из корневой папки проекта выполните:

```bash
python PythonApplication1.py
```
После запуска программа выводит приветствие:

text
Hello, World!
## Работа в Visual Studio
Для запуска проекта в Visual Studio необходимо:

Открыть файл решения PythonApplication1.slnx.

Убедиться, что выбран интерпретатор Python.

Нажать Ctrl + F5 для запуска без отладки.
